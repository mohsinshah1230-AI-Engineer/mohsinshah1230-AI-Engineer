- Automated enrichment via browser automation + Crawlee/Google Maps scraping, validated by live website checks, deliverable email formats, and verified phone numbers

**[ExcelsCRM](https://excelscrm.com)** — Lead-to-Sales Pipeline & Team Management Platform *(live)*
- Full-cycle CRM built around a Leads → Appointments → Proposals → Sales (LAPS) pipeline with integrated calendar sync for booking meetings directly with leads
- Role-based access control: user creation, role assignment, action-level audit logging, plus workflow automations for repetitive CRM tasks
- Team management: configurable work time-slots, check-in/check-out tracking, and per-user activity/performance dashboards
